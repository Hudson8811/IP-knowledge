# IP Knowledge

Static HTML/CSS implementation of the knowledge hub.

- `index.html` — main page
- `article.html` — main guide article
- `currency-control.html` — regular article example
- `css/style.css` — all styles and responsive rules

There is no JavaScript. Open `index.html` in a browser or serve the folder with any static web server.
